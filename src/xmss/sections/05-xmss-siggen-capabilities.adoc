
[[xmss_sigGen_capabilities]]
==== XMSS sigGen Mode Capabilities Example

Below is an example of the registration for XMSS / sigGen / SP800-208

[source, json]
----
{
    "algorithm": "XMSS",
    "mode": "sigGen",
    "revision": "SP800-208",
    "prereqVals": [
        {
            "algorithm": "SHA",
            "valValue": "123456"
        }
    ],
    "capabilities": {
        "xmssModes": ["XMSS-SHA2_10_256", "XMSS-SHA2_10_192"]
    },
    "messageLength": [
        {
            "min": 8,
            "max": 65536,
            "increment": 1
        }
    ]
}
----
