
[[xmss_sigVer_capabilities]]
==== XMSS sigVer Mode Capabilities Example

Below is an example of the registration for XMSS / sigVer / SP800-208

[source, json]
----
{
    "algorithm": "XMSS",
    "mode": "sigVer",
    "revision": "SP800-208",
    "prereqVals": [
        {
            "algorithm": "SHA",
            "valValue": "123456"
        }
    ],
    "capabilities": {
        "xmssModes": ["XMSS-SHA2_10_256", "XMSS-SHAKE256_10_192"]
    },
    "messageLength": [1024]
}
----
