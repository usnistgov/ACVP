=== xofDRBG Algorithm Registration Properties

Each SP800-90Ar2 xofDRBG algorithm capability advertised is a self-contained JSON object using the following values.

[[caps-table]]
.xofDRBG Algorithm Capabilities JSON Values
|===
| JSON Value | Description | JSON type | Valid Values

| algorithm | The xofDRBG algorithm to be validated | string | See <<supported>>
| mode | The xofDRBG mode to be validated | string | See <<supported>>
| revision | ACVP Test version | string | See <<supported>>
| prereqVals | Prerequisite algorithm validations | object with algorithm and valValue properties | See above
| reseed | Whether the implementation supports reseeding | array of boolean | [true, false]
| entropyInputLen | The lengths of entropy input supported | domain | Min: 128, Max: 4096, Increment: 8
| personStringLen | The personalization string lengths supported | domain | Min: 0, Max: 672, Increment: 8
| additionalInputLen | The additional input lengths supported | domain | Min: 0, Max: 672, Increment: 8
| returnedBitsLen | The output bit lengths supported | domain | Min: 0, Max: 2048, Increment: 8
|===

    {
